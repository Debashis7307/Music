# Explainable AI (XAI) Features

## Overview

The Smart Music Recommendation System now includes comprehensive Explainable AI (XAI) functionality that helps users understand **why** specific songs were recommended. This transparency builds trust and helps users discover music that truly matches their preferences.

## XAI Features

### 1. **Overall Similarity Score**
- Displays a percentage showing how similar the recommended song is to your selected track
- Color-coded circular indicator:
  - 🟢 Green (80%+): Very similar
  - 🟠 Orange (60-79%): Moderately similar  
  - 🔴 Red (<60%): Less similar but still relevant

### 2. **Feature Analysis Chart**
- Interactive bar chart showing similarity across all 15 audio features
- Features include: valence, energy, danceability, acousticness, and more
- Hover over bars to see feature descriptions
- Color-coded bars matching similarity levels

### 3. **Top Matching Features**
- Highlights the 3-5 most similar features between songs
- Each feature shows:
  - Feature name and description
  - Similarity percentage
  - Why this feature matters for music taste

### 4. **AI Reasoning**
- Human-readable explanations generated by the AI
- Explains the recommendation logic in plain language
- Examples:
  - "Both songs have very similar energy and danceability"
  - "This song shares several key characteristics with your selected track"

### 5. **Detailed Feature Comparison**
- Complete table comparing all audio features
- Shows original vs recommended song values
- Similarity percentages for each feature
- Feature descriptions for better understanding

## How to Use XAI Features

1. **Search for a song** using the search bar
2. **Select a song** from search results to get recommendations
3. **Click the "🤖 Why?" button** next to any recommended song
4. **Explore the explanation modal** with:
   - Overall similarity score
   - Interactive feature chart
   - Top matching features
   - AI reasoning
   - Detailed comparison table

## Technical Implementation

### Backend (app.py)
- `calculate_feature_similarity()`: Computes feature-level similarities
- `generate_explanation()`: Creates human-readable explanations
- Enhanced `/recommend` endpoint with XAI data
- New `/explain/<track_id>/<rec_track_id>` endpoint for detailed analysis

### Frontend
- **Interactive modal** for displaying explanations
- **Chart.js integration** for feature visualization
- **Responsive design** for mobile and desktop
- **Smooth animations** and user-friendly interface

### Audio Features Explained

| Feature | Description | Impact on Recommendations |
|---------|-------------|--------------------------|
| **Valence** | Musical positiveness (happy vs sad) | Matches emotional tone |
| **Energy** | Intensity and powerful feeling | Similar energy levels |
| **Danceability** | How suitable for dancing | Matching groove and rhythm |
| **Acousticness** | Whether the track is acoustic | Instrumental vs electronic |
| **Speechiness** | Presence of spoken words | Vocal vs instrumental focus |
| **Tempo** | Speed/pace (BPM) | Similar pacing preferences |
| **Loudness** | Overall volume level | Dynamic range matching |
| **Liveness** | Audience presence in recording | Studio vs live preference |
| **Instrumentalness** | Vocal content level | Singing vs instrumental |
| **Key** | Musical key | Harmonic compatibility |
| **Mode** | Major or minor scale | Mood matching |
| **Explicit** | Contains explicit lyrics | Content appropriateness |
| **Popularity** | Song/artist popularity scores | Mainstream vs niche taste |
